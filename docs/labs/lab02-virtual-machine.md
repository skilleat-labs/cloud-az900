# Lab 02 · 가상 머신 만들기

!!! info "실습 정보"
    - **주제**: IaaS(Infrastructure as a Service) 컴퓨팅
    - **예상 시간**: 20분
    - **배우는 것**:
        1. Azure 가상 머신(VM)을 포털에서 직접 생성하는 방법
        2. VM 크기(SKU)와 비용의 관계
        3. "중지됨"과 "할당 취소됨"의 차이 및 비용 영향

!!! warning "사전 준비"
    Lab 01에서 만든 리소스 그룹 `rg-[본인이름]-lab`이 있어야 합니다.
    Lab 01을 먼저 완료해주세요.

---

## 실습 목표

가상 머신(VM)은 IaaS의 대표적인 서비스입니다.
물리 서버를 직접 구매하지 않고 Azure에서 필요한 만큼 컴퓨팅 자원을 빌려 사용합니다.
이번 실습에서는 Windows Server VM을 만들고, 중지 및 크기 조회 기능을 체험합니다.

---

## Step 1 · 가상 머신 만들기 시작

> Azure Portal → 상단 검색창 → "가상 머신" → 만들기 → Azure 가상 머신

1. Azure Portal 상단 **검색창**에 `가상 머신`을 입력합니다.
2. 검색 결과에서 **가상 머신**을 클릭합니다.
3. 가상 머신 목록 페이지에서 **+ 만들기** 버튼을 클릭합니다.
4. 드롭다운 메뉴에서 **Azure 가상 머신**을 선택합니다.

---

## Step 2 · 기본 사항 설정

가상 머신 만들기 화면의 **기본 사항** 탭에서 아래 항목을 설정합니다.

### 2-1. 프로젝트 세부 정보

| 항목 | 값 |
|------|-----|
| 구독 | 강사가 제공한 구독 선택 |
| 리소스 그룹 | `rg-[본인이름]-lab` (Lab 01에서 생성) |

### 2-2. 인스턴스 세부 정보

| 항목 | 값 |
|------|-----|
| 가상 머신 이름 | `vm-[본인이름]-01` (예: `vm-gildong-01`) |
| 지역 | Korea Central |
| 가용성 옵션 | 가용성 영역 |
| 가용성 영역 | 영역 1 |
| 이미지 | Windows Server 2022 Datacenter - Gen2 |
| 크기 | Standard_B1s (아래 방법으로 선택) |

!!! tip "VM 크기 선택 방법"
    1. **크기** 항목 옆의 **모든 크기 보기**를 클릭합니다.
    2. 검색창에 `B1s`를 입력합니다.
    3. **Standard_B1s** (1 vCPU, 1GiB 메모리)를 선택합니다.
    4. **선택** 버튼을 클릭합니다.

    Standard_B1s는 실습용으로 가장 저렴한 옵션 중 하나입니다.

### 2-3. 관리자 계정

| 항목 | 값 |
|------|-----|
| 사용자 이름 | `azureuser` |
| 암호 | 안전한 암호 설정 (대/소문자 + 숫자 + 특수문자 포함) |
| 암호 확인 | 동일한 암호 재입력 |

!!! warning "주의"
    암호는 **12자 이상**이며 복잡성 요구 사항을 충족해야 합니다.
    예시: `AzureLab2024!`
    암호를 꼭 기억해두세요.

### 2-4. 인바운드 포트 규칙

| 항목 | 값 |
|------|-----|
| 공용 인바운드 포트 | 선택한 포트 허용 |
| 인바운드 포트 선택 | RDP (3389) |

!!! warning "보안 주의"
    실습 환경에서만 RDP 포트를 공개적으로 열어둡니다.
    실제 운영 환경에서는 Azure Bastion 또는 VPN을 통해 접속하는 것이 권장됩니다.

---

## Step 3 · 검토 및 만들기

> 나머지 탭(디스크, 네트워킹, 관리 등)은 기본값으로 유지합니다.

1. 설정을 모두 마쳤으면 **검토 + 만들기** 버튼을 클릭합니다.
2. 상단에 **유효성 검사 통과** 녹색 메시지가 표시되는지 확인합니다.
3. 예상 비용을 오른쪽 또는 하단에서 확인합니다.
4. **만들기** 버튼을 클릭합니다.

!!! tip "배포 대기"
    VM 배포는 일반적으로 **2~3분** 정도 소요됩니다.
    "배포 진행 중" 화면에서 각 항목이 순서대로 생성되는 과정을 확인할 수 있습니다.

    생성되는 리소스 목록:
    - 가상 머신 (VM 본체)
    - 네트워크 인터페이스 카드 (NIC)
    - 공용 IP 주소
    - 네트워크 보안 그룹 (NSG)
    - OS 디스크

5. "배포가 완료되었습니다" 메시지가 표시되면 **리소스로 이동**을 클릭합니다.

!!! success "완료"
    가상 머신이 성공적으로 생성되었습니다.
    VM 개요 페이지에서 공용 IP 주소와 상태(실행 중)를 확인할 수 있습니다.

---

## Step 4 · VM 중지 (할당 취소)

> VM을 사용하지 않을 때는 반드시 할당 취소 상태로 변경하여 비용을 절감합니다.

### 4-1. VM 중지

1. VM 개요 페이지 상단의 **중지** 버튼을 클릭합니다.
2. "가상 머신을 중지하시겠습니까?" 확인 대화상자에서 **확인**을 클릭합니다.
3. VM 상태가 변경되는 것을 확인합니다.

### 4-2. 상태 변화 관찰

| 상태 | 의미 | 컴퓨팅 비용 |
|------|------|------------|
| 실행 중 | VM이 동작 중 | 발생 |
| 중지됨 | OS 내에서 종료 | **발생** (주의!) |
| 중지됨(할당 취소됨) | Azure에서 완전히 반납 | 발생 안 함 |

!!! warning "중요한 차이: 중지됨 vs 할당 취소됨"
    단순히 VM을 "중지"하면 OS는 꺼지지만 Azure 인프라(하드웨어)는 계속 예약됩니다.
    Azure Portal의 **중지** 버튼을 클릭하면 자동으로 **할당 취소** 상태로 변경됩니다.

    - **할당 취소됨**: 컴퓨팅(CPU, 메모리) 비용 중단
    - 단, **디스크**와 **공용 IP** 비용은 할당 취소 후에도 계속 발생!

4. 상태가 **"중지됨(할당 취소됨)"** 으로 변경될 때까지 기다립니다. (약 1분 소요)

---

## Step 5 · VM 크기 확인

> 다양한 VM 크기를 비교하며 IaaS의 유연성을 확인합니다.

1. VM 왼쪽 메뉴에서 **크기**를 클릭합니다.
2. 사용 가능한 VM 크기 목록이 표시됩니다.
3. 각 크기의 vCPU, 메모리(GiB), 예상 비용을 비교합니다.

!!! tip "VM 크기 계열 이해"
    | 계열 | 용도 |
    |------|------|
    | B 계열 | 버스트 가능, 개발/테스트용 (저렴) |
    | D 계열 | 범용, 일반 워크로드 |
    | E 계열 | 메모리 최적화, DB용 |
    | F 계열 | 컴퓨팅 최적화, 배치 처리 |
    | N 계열 | GPU 포함, AI/ML용 |

4. 크기는 VM이 할당 취소된 상태에서 변경할 수 있습니다.

## 실습 정리

!!! danger "비용 주의"
    VM은 실행 중이 아니어도 **디스크와 공용 IP 비용**이 계속 발생합니다.
    반드시 아래 순서로 VM과 관련 리소스를 삭제하세요.

**VM 및 연결 리소스 삭제 방법:**

1. 리소스 그룹(`rg-[본인이름]-lab`)으로 이동합니다.
2. 목록에서 다음 리소스를 모두 선택합니다.
   - 가상 머신 (`vm-[이름]-01`)
   - 디스크 (`vm-[이름]-01_OsDisk_...`)
   - 공용 IP 주소 (`vm-[이름]-01-ip`)
   - 네트워크 인터페이스 (`vm-[이름]-01...`)
   - 네트워크 보안 그룹 (`vm-[이름]-01-nsg`)
3. **삭제** 버튼 클릭 → 확인

!!! tip "팁"
    또는 리소스 그룹 자체를 삭제하면 내부의 모든 리소스가 한번에 삭제됩니다.
    단, Lab 03~05에서 같은 리소스 그룹을 사용하므로 VM 관련 리소스만 선택 삭제하세요.

## 핵심 정리

1. **IaaS(가상 머신)는 OS부터 모든 것을 직접 관리**합니다.
   OS 설치, 패치, 보안 설정, 애플리케이션 설치까지 모두 사용자의 책임입니다.
   그만큼 유연하지만, 관리 부담도 큽니다.

2. **VM은 크기(SKU)에 따라 비용이 달라집니다.**
   vCPU와 메모리가 많을수록 비용이 증가합니다.
   실습/개발 환경에서는 B1s와 같은 소형 VM을 사용하세요.

3. **"할당 취소됨" 상태에서만 컴퓨팅 비용이 중단됩니다.**
   단, 디스크와 공용 IP는 별도로 비용이 발생하므로
   장기 미사용 시에는 리소스 전체를 삭제하는 것이 최선입니다.
